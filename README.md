# Ebnul Hasan Mahi Portfolio

Production portfolio for **Ebnul Hasan Mahi**, a Software Engineering student and Full-Stack Developer based in Dhaka, Bangladesh.

This portfolio is built as a premium static website using vanilla HTML, CSS, and JavaScript. It highlights real projects, recruiter-friendly case studies, strong visual hierarchy, responsive layouts, and production metadata for SEO and deployment.

## Featured Projects

- **Hospital Doctor Duty Roster** — healthcare scheduling application with role-based workflows.
- **PowerPulse BD** — energy monitoring dashboard with solar, battery, and outage views.
- **Data Privacy Vault** — Java/OOP security-focused data storage project.
- **Mini Solar Panel Monitor** — Java energy simulation and monitoring project.

## Tech Stack

- HTML5
- CSS3 with custom properties
- Vanilla JavaScript
- Optimized WebP assets
- Vercel static deployment

## Production Details

- Semantic HTML structure
- Responsive desktop, tablet, and mobile layouts
- Accessible navigation, skip link, focus states, labels, and form errors
- Lazy-loaded project imagery with stable dimensions
- Open Graph and Twitter metadata
- JSON-LD structured data
- `robots.txt`
- `sitemap.xml`
- `manifest.json`
- Favicons and Apple touch icon

## Local Preview

```bash
npm run preview
```

Then open the local URL shown in the terminal.

## Deploy

```bash
vercel --prod
```

The project is intentionally standalone. Do not deploy it from the Hospital Doctor Duty Roster or PowerPulse BD repositories.
